ENGINE-SIM WEB PORT

An unofficial browser port of engine-sim, the real-time engine simulator created by AngeTheGreat (Ange Yaghi). The simulation and sound synthesis are his code, compiled to WebAssembly.

Press A for ignition, hold S to crank, then Q W E R or the throttle slider.

Not affiliated with or endorsed by the original author. Want the real thing? Get the desktop app and support the author on Patreon.

KEYBOARD
AIgnition on / off
S (hold)Starter motor
Q / W / E / R (hold)Throttle 1% / 10% / 20% / 100%
Space + wheelFine throttle (holds the setting)
↑ / ↓Gear up / down (below 1st is neutral)
Shift (hold)Disengage clutch
T / U (hold)Slip clutch less / more · Y keeps it
DDynamometer on / off
HDyno hold · G + wheel sets hold speed
1 – 5 (hold)Slow motion (1/10 … 1/1000)
Z / X / C / V / B + wheelVolume / convolution / HF gain / LF noise / HF noise
N + wheelSimulation frequency
M / ,Render layer deeper / shallower
F1 / F2 / F3Rotate view / reset
